HOW IT WORKS

PACE works alongside Windows security.

It is a companion interface, not a replacement for a full antivirus product.

01

Open PACE on Windows

The app queries the local Microsoft Defender status through Windows PowerShell.

02

Request a scan

Choose Quick Scan or Full Scan. Windows may display a User Account Control prompt.

03

Review the result in Windows Security

Use Windows Security and Protection history for the authoritative scan and remediation status.

IMPORTANT TO KNOW

What Beta 0.2 does — and does not do.

✓This beta can

  • Read selected Microsoft Defender status fields.
  • Request a Defender quick or full scan.
  • Open Windows Security for result review.

!This beta cannot

  • Independently detect every virus or advanced threat.
  • Guarantee that a PC is clean or continuously protected.
  • Replace Microsoft Defender or another trusted antivirus.
