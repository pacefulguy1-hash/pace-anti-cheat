# PACE Anti-Cheat 0.2 Beta — Windows

This is an unsigned beta installer for a small Windows desktop interface to Microsoft Defender.

## What it does
- Reads selected local Microsoft Defender status fields.
- Requests a Microsoft Defender Quick Scan or Full Scan.
- Opens Windows Security so you can inspect the authoritative results.

## Important limitations
- PACE does not include its own malware-detection engine or real-time protection.
- A scan request being accepted does not mean the scan has finished.
- This beta installer is not digitally signed. Windows SmartScreen may show a warning.
- Test the installer before publishing the draft release. Do not treat this beta as a replacement for Microsoft Defender or another trusted antivirus.
